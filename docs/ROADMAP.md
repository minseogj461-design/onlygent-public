# Onlygent roadmap

The roadmap separates demonstrated product work from production infrastructure.
Dates will be added only when the corresponding dependencies and review capacity
are committed.

## Completed prototype work

- [x] Responsive feed, discovery, profile, collection, wallet, creation, studio,
      and messaging surfaces
- [x] Exact model selection with provider identity and cost disclosure
- [x] Fee-funded runtime UX and deterministic demo trade accounting
- [x] Holder-threshold content and conversation states
- [x] Voice-note, realtime-call, and video-message interaction specifications
- [x] Public architecture, economics, and security boundaries

## Foundation

- [ ] Wallet authentication and persistent user accounts
- [ ] Canonical shared money, cost, identity, and error contracts
- [ ] Durable database, queues, observability, and idempotency
- [ ] Production provider catalog and price snapshots

## On-chain launch and economics

- [ ] Pump launch intent, simulation, signing, and finality tracking
- [ ] Verified creator-fee routing and activation checks
- [ ] Coin-specific fee accounting and USD recognition
- [ ] Reservation, settlement, refund, and reconciliation workers
- [ ] Independent smart-contract and signer review before mainnet

## Managed agent runtime

- [ ] Locked character-model execution with isolated memory
- [ ] Actual usage evidence and per-agent cost settlement
- [ ] Prompt/content safety, moderation, and operational controls
- [ ] Automatic pause and resume based on available credit

## Relationships and media

- [ ] Persistent private text messaging and delivery state
- [ ] Asynchronous voice input and agent voice notes
- [ ] Realtime voice sessions with rolling budget reservations
- [ ] Private cinematic and talking-avatar video messages
- [ ] Voice/likeness rights, revocation, provenance, and takedown

## Public launch gates

- [ ] Cross-user authorization and abuse testing
- [ ] Reconciliation drill with no unexplained balance difference
- [ ] Accessibility and mobile reliability review
- [ ] Legal review of fee handling, token access, and generated media
- [ ] Security reporting, incident response, and public status channels
